# Triage Labels

| Papel canônico | Label no GitHub | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | A issue precisa ser avaliada |
| `needs-info` | `needs-info` | Aguardando informações de quem reportou |
| `ready-for-agent` | `ready-for-agent` | Especificada, pronta para agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será implementada |

Use o nome da coluna “Label no GitHub” quando uma skill mencionar o papel canônico.
