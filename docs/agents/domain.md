# Domain Docs

## Antes de explorar

- Leia `GLOSSARY.md` na raiz; se existir `GLOSSARY-MAP.md`, siga-o e leia os glossários relevantes.
- Leia ADRs relevantes em `docs/adr/`; se algum desses arquivos não existir, prossiga sem sinalizar a ausência.

## Estrutura

Este é um repositório single-context: um `GLOSSARY.md` na raiz e ADRs em `docs/adr/`.

## Vocabulário

Use os termos definidos no glossário em issues, propostas, hipóteses e testes. Evite sinônimos marcados como indesejados. Se um conceito necessário ainda não existir, registre a lacuna para discussão de domínio.

## Conflitos com ADRs

Se uma saída contrariar um ADR existente, explicite o conflito em vez de substituí-lo silenciosamente.
